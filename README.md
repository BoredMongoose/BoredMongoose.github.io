# boredmongoose.github.io

Personal portfolio of **Milind Saxena**, data analyst. Live at https://boredmongoose.github.io

Each project answers one question with public data:
- [TTC subway delays](https://github.com/BoredMongoose/ttc-subway-delays): why Toronto's subway delays nearly doubled since 2014
- [A/B test: Cookie Cats](https://github.com/BoredMongoose/ab-test-cookie-cats): should a mobile game move its first gate, and was the experiment sound?
- [Telco churn](https://github.com/BoredMongoose/telco-churn-profit): who will cancel, and who's worth saving?
- [UPI vs. cash](https://github.com/BoredMongoose/upi-cash-paradox): why India still holds record cash
- [Express Entry draws](https://github.com/BoredMongoose/express-entry-draws): what CRS score you need for Canadian PR in 2026
- [Delhi smog](https://github.com/BoredMongoose/delhi-smog): Diwali crackers vs. crop-fire smoke
- [Moneyball IPL](https://github.com/BoredMongoose/ipl-moneyball): which IPL auction buys were busts and which were steals

Built with plain HTML, CSS and a little JavaScript.
