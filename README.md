# boredmongoose.github.io

Personal portfolio of **Milind Saxena**, data analyst. Live at https://boredmongoose.github.io

Three data projects, each answering a question with public data:
- [Moneyball IPL](https://github.com/BoredMongoose/ipl-moneyball): which IPL auction buys were busts and which were steals
- [Delhi smog](https://github.com/BoredMongoose/delhi-smog): Diwali crackers vs. crop-fire smoke
- [UPI vs. cash](https://github.com/BoredMongoose/upi-cash-paradox): why India still holds record cash

Built with plain HTML, CSS and a little JavaScript.
